## How PageForge Works

### 1. Prepare Your CSV

Create a CSV file with the data you want to scale.

Example:

```csv
City,State,Service,Keyword,Offer,Phone
Austin,Texas,Emergency Plumbing,emergency plumber Austin,24/7 plumbing help,(555) 123-4567
Dallas,Texas,Drain Cleaning,drain cleaning Dallas,Same-day drain service,(555) 123-4567
Miami,Florida,Water Heater Repair,water heater repair Miami,Fast water heater repair,(555) 123-4567
```

### 2. Create One WordPress Template

Use a reusable page template with tokens.

Example:

```html
<h1>{Service} in {City}, {State}</h1>

<p>Looking for trusted {Service} in {City}? Our team helps local customers with fast, reliable, and professional service.</p>

<p>Call us today at {Phone} to get {Offer}.</p>
```

### 3. Generate SEO Pages

PageForge reads each CSV row and creates pages such as:

- `/emergency-plumbing-austin/`
- `/drain-cleaning-dallas/`
- `/water-heater-repair-miami/`

### 4. Add SEO Meta

Generate or sync:

- SEO title
- Meta description
- Page slug
- Schema
- Internal links
- Sitemap blocks

### 5. Publish, Index, and Track

Submit pages through your normal SEO workflow:

- XML sitemap
- Google Search Console
- Internal links
- Contextual backlinks
- Supporting blog posts
- Ranking tracker

## Rank in 24 Hours Workflow

Use this as a practical campaign playbook.

### Step 1 — Choose Low-Competition Long-Tail Keywords

Start with keyword patterns that are specific and easy to match.

Good examples:

- `{Service} in {City}`
- `{Product} for {Niche}`
- `{Software} for {Business Type}`
- `{Category} near {Location}`
- `{Problem} solution in {City}`

Avoid starting with broad keywords like:

- SEO
- WordPress
- marketing
- plumber
- software

### Step 2 — Build a Small Test Cluster

Start with 50 to 100 pages.

Do not publish 10,000 thin pages on day one.

A strong first cluster could include:

- 25 city pages
- 25 service pages
- 10 supporting blog posts
- 1 sitemap hub page
- 1 pillar article

### Step 3 — Add Real Value to Every Page

Each generated page should have:

- Unique local or niche-specific copy
- Clear search intent match
- Useful headings
- FAQs
- Internal links
- Schema
- Strong call to action
- No duplicate slugs
- No empty token output
- No thin boilerplate content

### Step 4 — Build Internal Links

Create a hub page that links to all generated pages.

Example hub structure:

```text
Programmatic SEO Hub
├── Plumbing Services in Texas
│   ├── Emergency Plumbing in Austin
│   ├── Drain Cleaning in Dallas
│   └── Water Heater Repair in Houston
├── Plumbing Services in Florida
│   ├── Emergency Plumbing in Miami
│   ├── Drain Cleaning in Orlando
│   └── Water Heater Repair in Tampa
```

### Step 5 — Submit for Indexing

Use:

- Google Search Console
- XML sitemap
- Internal links from live pages
- Homepage or footer links for important hubs
- Fresh blog posts linking to generated pages

### Step 6 — Build Backlinks

Use contextual links from:

- Official website blog posts
- YouTube descriptions
- WordPress.org plugin page
- GitHub repository
- Product directories
- SaaS directories
- Agency case studies
- Tutorial articles
- LinkedIn posts
- Newsletter mentions

### Step 7 — Track the Winners

After pages are indexed, track:

- Impressions
- Clicks
- Ranking keywords
- Pages that get discovered fastest
- Pages stuck outside top 50
- Queries with high impressions but low CTR
- Pages that need more content or backlinks

Then update the CSV, improve templates, and regenerate or optimize.

## SEO Quality Checklist

Before publishing a bulk page campaign, check:

- [ ] Every CSV row has complete data.
- [ ] No empty `{Token}` placeholders remain.
- [ ] Page titles are unique.
- [ ] Meta descriptions are unique.
- [ ] Slugs are clean and readable.
- [ ] Internal links point to real pages.
- [ ] Schema output is valid.
- [ ] Pages are not thin or duplicated.
- [ ] Every page matches a real search intent.
- [ ] Sitemap includes generated pages.
- [ ] Important pages are linked from hub pages.
- [ ] Google Search Console is connected.
- [ ] Rankings are tracked after publishing.
